# 🌌 High-Performance 8D Hyperspace Projection Engine & Synthetic Life Ecosystem

A highly optimized real-time graphics visualization pipeline, viewport sandbox, and **homeostatic simulation engine** built with **Python** and **Pygame Community Edition**. This engine models random Gaussian particle distributions in an 8-dimensional hyperspace (X₁ through X₈), applies complex multi-planar rotational transformations, and maps the output onto a responsive 2D dashboard matrix featuring alpha-blended radial glow rings.

This architecture introduces an automated **Auto-Equilibrium Homeostasis System**, turning the script into a self-sustaining, ambient computational life form that manages its own node populations natively.

---

## 🧬 Biomorphic & Architectural Upgrades

* **Self-Regulating Homeostasis (`EQUILIBRIUM_CONFIG`):** Constantly monitors the system mass density. It maintains a safe, stable baseline population (\(100 \le \text{nodes} \le 150\)) using timed mathematical birth and decay loops.
* **Autonomous Inflow (Cellular Birth):** Automatically streams a fresh cluster block (+18 points) every 1.5 seconds to expand the hyper-ball matrices naturally.
* **Autonomous Outflow (Cellular Purge):** Runs density sweeps every 2.0 seconds. If the global particle count crosses a threshold, it fires an automated removal pulse to slice out excess vertices and maintain structural balance.
* **Manual Override Interlock (`[A]`):** Features a hotkey toggle to halt the automatic ecosystem instantly, shifting the visualizer between an organic `✓ AUTO` loop and a user-controlled `✗ MANUAL` sandbox mode.
* **Categorized HUD Telemetry & Status Readout:** Explicitly logs active ecosystem data tracks, counting total live particles, tracking queue limits, and displaying homeostatic status flags.

## 📐 Math Projection Pipeline Overview

Human vision is restricted to three geometric dimensions. To visual structural activity in an 8-dimensional coordinate structure, this script employs **Time (T)** as a processing vehicle:

1. **Trigonometric Rotation:** High-dimensional positions roll across 4 coupled rotation tracks inside native hyperspace (`angle_1` to `angle_4`).
2. **Dimension Reduction Slicing:** Higher indexes are systematically reduced to compute spatial depth perspective, guarded against division-by-zero bounds errors (Z-depth calculation).
3. **Flat Plane Projection:** Mapped values are dynamically amplified and translated onto the physical horizontal X₁ and vertical X₂ screen space coordinates.
