# Hyperspace Grid View (8D Projected)

A real-time higher-dimensional visualization and simulation engine built with Python and Pygame CE. This engine models the trajectory, behavior, and overlapping points of separate matrices moving through 8-dimensional space. By applying dynamic, multi-planar rotation transformations over a continuous time axis, hidden structural dimensions smoothly transition into an observable 2D vector coordinate mapping grid.

## 🚀 System Features
* **Multi-Planar 8D Rotation:** Simulates continuous multidimensional spatial drift across 4 native coordinate tracking planes simultaneously.
* **Gaussian Mass Density Clusters:** Renders high-dimensional hyper-balls using organic probabilistic core cloud distributions.
* **Real-time Junction Tracker:** Calculates structural matrix alignments on the fly, instantly highlighting spatial intersections with a glowing coordinate anchor.
* **Variable Hyperspace Speed Matrix:** Features an integrated acceleration engine to adjust structural rotation states dynamically in real time.
* **Telemetry Control Dashboard:** Houses an ongoing HUD displaying 8D Euclidean bounds, mapped matrix vectors, active processing planes, and real-time speed values.

## 🛠️ Project Core Stack
* **Language Environment:** Python 3.14+
* **Framework:** Pygame Community Edition (`pygame-ce`)
* **Mathematical Utilities:** Python Native Math Library

## ⚙️ Quick Start

### 1. Verification and Setup
Ensure your local workspace has the updated, high-performance community package variant capable of supporting modern Python runtime engines:
```bash
pip install pygame-ce
```

### 2. Execution
Run the core visualization pipeline file directly within your development environment:
```bash
python hyperspace_visualizer.py
```

## 🎮 Interface & Interactive Controls

Take direct control of the 8-dimensional slicing engine using interactive keyboard inputs:

| Input / Command | Operational Function |
| :--- | :--- |
| **`UP ARROW`** | **Accelerate Hyperspace Warp Factor** (Increases rotation speed up to a maximum of 5.0x) |
| **`DOWN ARROW`** | **Decelerate Hyperspace Warp Factor** (Slows down rotation speed down to a complete 0.0x freeze) |
| **`SPACEBAR`** | **Pause / Play** (Instantly stops or resumes all multidimensional rotation loops) |
| **`P`** | **Toggle Projection Method** (Switches graphics processing between *Perspective* and *Orthographic* modes) |
| **`ESC`** | **System Terminate** (Safely shuts down active memory processes and closes the rendering window) |
