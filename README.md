# 🌌 8D Hyperspace Projection Engine

A real-time, higher-dimensional graphics visualization engine built with **Python** and **Pygame Community Edition**. This application maps, rotates, and projects complex 8-dimensional dataset point clouds onto a flat 2D viewport matrix. By translating hidden hyperspace axes across time, it creates a hypnotic sci-fi user interface displaying multidimensional structural drift.

---

## 🚀 Key Features

* **8D Planar Rotation Engine:** Executes coupled sine/cosine matrix transformations across 4 independent higher-dimensional planes simultaneously (`angle_1` through `angle_4`).
* **Dual Hyper-Ball Volumetric Simulations:** Generates two distinct 80-particle cloud bodies using a random Gaussian distribution shell offset natively in hyperspace.
* **Dual Math Projection Pipelines:** Instantly swaps between a depth-calculated **Perspective** mode and a strict mechanical **Orthographic** slice map.
* **Independent Intersecting Core:** Anchors the structural midpoint of the hyper-balls with a prominent, decoupled **Pure White Sphere** that orbits freely on its own computational cycle.
* **Dynamic Coordinate Wireframe:** Dynamically weaves structural vector mesh lines between vertex anchors to draw an analytical cage instead of a loose dust cloud.
* **Integrated Telemetry HUD:** Houses an interface dashboard monitoring pixel distance, visual themes, active layout modes, and separate loop speed channels.

## 🎮 Real-Time Interface Controls

Take complete control over the hyperspace environment using interactive keyboard binds:

| Key Input | Engine Operation Command |
| :--- | :--- |
| **`SPACEBAR`** | **Pause / Resume** the global rotation timeline loop. |
| **`P`** | **Toggle Projection Pipelines** (*Perspective* vs. *Orthographic*). |
| **`UP / DOWN ARROWS`** | **Adjust Cloud Warp Factor** (Speeds up or slows down the outer particle clusters). |
| **`W / S`** | **Adjust Center Core Velocity** (Accelerates or brakes only the white inner sphere). |
| **`M`** | **Toggle Wireframe Matrix** (Draws or hides connecting mesh vectors). |
| **`T`** | **Cycle System Themes** (Morphs UI colors through preset filters). |
| **`ESC`** | **Graceful Quit** (Clears active system memory and terminates the window process). |

## 📐 Project Architecture & Math Concept

Human eyes can only process three physical dimensions. To render an **8-dimensional object ($X_1$ to $X_8$)**, this program uses **Time ($T$)** as a vehicle. 

1. **Native 8D Shifting:** The engine takes fixed 8D coordinates and rolls them through trigonometric rotation matrices.
2. **Dimension Reduction:** Dimensions $X_3$ through $X_8$ are compressed to simulate spatial "depth" ($Z$-depth).
3. **Screen Projection:** The remaining coordinates are plotted across the horizontal $X_1$ and vertical $X_2$ display grid axes.

As the mathematical loops run, dimensions that were once entirely invisible smoothly rotate into our visible tracking space, letting you watch the higher-dimensional bodies morph and step right in front of you.
